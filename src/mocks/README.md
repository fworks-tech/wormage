# src/mocks — MSW handlers

`handlers.ts` translates the mock REST surface into MSW request handlers; `browser.ts` creates the worker.

Every handler:

1. awaits the scenario latency (120 ms normal, 1500 ms slow),
2. returns `503` in the `error` scenario,
3. returns empty pages in the `empty` scenario,
4. delegates to `src/api/mockServer.ts` for the real logic.

This file contains no business rules: pagination, ranking, fixtures and idempotency live in `mockServer.ts` so the Axios in-process adapter can reuse them.

The worker file itself is generated by `npx msw init public --save` and committed at `public/mockServiceWorker.js`. Vercel must serve it from `/` without the SPA rewrite (see `vercel.json`).
